# V31 application/native resource acceptance — bounded, not universal

## Selected question and scope

The only new resource question is the predefined strict Phase2 stability assessment in V31_PHASE2_DECISION_PLAN.md: does the unchanged immediate-stage budget recur out of sample? Results and all twelve raw observations belong in V31_PHASE2_RESULTS.md. It is not a new decoder/audio/observer/animation root-cause sweep. No broader resource question is selected without a concrete observed defect, owner, lifecycle boundary, trigger and failure. A budget failure alone is not an owner or a causal diagnosis.

Application leak attribution requires an application-owned reachable resource/callback surviving its actual ownership boundary, plus causal evidence identifying that owner. The current instrumentation records original allocated counters, shell identity and post-assertion connected DOM/frame/dialog/loading counts. Connected observations count main-document elements, not text nodes, inaccessible child documents or shadow-root internals. It does not inspect every strong retaining path, enumerate every timer or establish browser-native disposal. A fresh context closing at the test end is isolation, not evidence that every resource was already released at an earlier route boundary.

## Repair decision

No runtime cleanup is justified merely by allocated-node variability or an inaccessible opaque/native owner. No new controller, writer, engine, timer cancellation, manual iframe removal, animation cancellation/disable, dependency upgrade, arbitrary settling delay or runtime GC is introduced. All original assertion stages, budgets, names and timeouts remain unchanged. Runtime identity is verified against sealed V30, and full mandatory regressions independently verify the exact V31 ZIP.

If a concrete contradiction appears, the written plan permits at most one matched post-stage check of that actual owner, not another general heap/blank-page/cancellation study. Outcomes and whether that permission was used must be stated in V31_PHASE2_RESULTS.md; no replacement successes may be substituted.
