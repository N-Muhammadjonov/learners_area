## Course roadmap

Original `src/lib/data/roadmap.ts:getCourseRoadmap("ielts",user.id)` supplies server-authorized course, ordered modules/units, only published or scheduled-due lessons, and own progress state or original default state. Client projection `data:{roadmap:null|{course:{title:string,description:null|string},modules:[{id:UUID,title:string,units:[{id:UUID,title:string,lessons:[{id:UUID,title:string,summary:null|string,state:locked|scheduled|available|assigned|in_progress|completed}]}]}]}}`. Minimize raw database columns server-side; never private notes, answers, raw learner rows or content blobs. Client validates identity uniqueness/types/state and copies display fields. Client validation is NOT server ownership/publication verification. Null course or404 uses existing not-found UI. Original page hides link only for locked; scheduled uses original source badge behavior (no invented label), not a new permission. Detail URL checks/release still server-authoritative. No opening-only progress credit.

Original `src/app/app/(shell)/grammar/page.tsx` and `src/lib/data/grammar.ts:getTopicMastery(ownUserId,area)` resolve visible published topics/exercises and latest own attempts; original service alone computes mastery. Query missing/emptytab→existing Lessons redirect; speaking→speaking; other suppliedtab→writing. Projection `data:{rows:[{topic:{id:UUID,title:string,skillArea:writing|speaking},totalExercises:nonnegativeInteger,masteryUnavailable:boolean,mastery:null|{scorePercent:number0..100,sessions:nonnegativeInteger,mastered:boolean}}]}`. Null mastery means unavailable, not0. Availability flag/null pair must agree. No answers/exercises/attempt corpus is returned to this catalogue. Client filters selected skill area, preserves source order and displays server results without recalculation, capping sessions or inferring mastered. Existing source display denominator3 extracted at build-time, not a new rule. Metadata retry reloads only current authorized route view, not an automatic mutation replay.

Server-owned publication, grammarVisibleTo/user scope and own-attempt filtering must remain as original; a client DTO/URL/session role is not a substitute.
