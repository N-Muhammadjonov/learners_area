Exit sends may set keepalive; an already-running request cannot be upgraded and document-exit delivery is best effort,not guaranteed. Route exit does not abort legitimate pending note transport; authority revocation does fence/cancel owned work. At most one awaited transport per panel; latest pending coalesced. Response ok:true acknowledges the exact submitted snapshot, not a normalized response string; empty/whitespace success clears original private server row while UI may show acknowledged raw whitespace.

V36 fixes two reproduced client races in this writer: edits reverting to old ACK now replace stale pending values and restore current text after different in-flight ACK; duplicate flush of identical in-flight snapshot no longer creates pending replay after failure. Failed snapshots await explicit retry unless a genuinely newer pending edit exists. Text remains visible; overlong never truncated; no storage/offline substitute. No second note writer/controller. Cross-tab/device/remount conflicts and timeout-aborted server transactions lack CAS/rollback guarantees; one awaited client request is not proof of exactly-once server commit. No claims beyond original per-panel ordering and observed fixture transports.
