# V16 timeline interpretation

Every raw row has sequence and host-monotonic receipt time, owner, sourceToken, part, canonicalAttempt, UI/navigation epoch, requestID/status/cancellation fields. Null explicitly means unavailable at that observer, not proof of absence. Child bridge timestamps are host receipt, not identical cross-realm clock values. Early probes use a synthetic canonical alias; final exact trace records actual fixture-only UUIDs so canonical replacements can be distinguished; no auth token/answers/content/audio logged.

1 source readiness: stage1; hydrated bridge message. 2 native part: stage2 plus native location grants; loop's desired part not confused with current parent part. 3 input: stage3; safe checked/answer-count snapshots. 4 intent: observer-installed-before-check then Review action. 5 authority: authority:read + correlated session/state/progress GETs. 6 accept or reject: authority:accept/error. 7 native Check allowed: action grant continuation, native storage changes. 8 feedback: native checked state/card/score assertions, not inferred server grades. 9 progress ACK: separate POST Network response and Review writer ACK/status. 10 checkpoint intent: storage changed plus immediate draftOnly bridge. 11 queue: writer:stage/save/drain requested/active flags. 12 issue/withhold: network PUT or staged requested:false without flush (must compare whole bounded timeline). 13 payload: checked integer list, count and synthetic canonical label; raw answers omitted. 14 response/abort: requestID terminal events. 15 original predicate: predicate.match; undefined false remains rejection. 16 own exact ACK: writer hooks and bridge hydration or mismatch guard; ReviewJournal raw-byte checks independently maintained. 17 expected UI: stage17 plus unchanged transcript/card/focus/reload/Retry assertions.

No request event does not alone prove no send; paired writer and bridge timer evidence establishes the controlled missing-flush case. HTTP200 is not journal ACK: independent exact-own-byte ReviewJournal checks remain mandatory and existing unit/source neighbors cover changed/raw/foreign/canonical cases. Historical V29 failing part/epochs/request IDs were not captured and are UNKNOWN, never filled from fresh runs.
