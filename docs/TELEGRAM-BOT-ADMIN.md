# Bot adminlari

Sayt `ADMIN` roli avtomatik bot admin emas.

Asosiy ega `TELEGRAM_OWNER_ID`. Uni bot orqali olib tashlab bo'lmaydi, o'zini OWNER qilib bo'lmaydi, o'ziga berilmagan ruxsatni olib bo'lmaydi.

Qo'shish: boshqaruv → Bot adminlari → Telegram raqamli ID va ruxsatlar.

Ruxsat o'chirilganda yoki admin nofaol qilinsa, keyingi so'rov darhol rad etiladi. Tugmani yashirish himoya emas: server har safar tekshiradi.

Bot admin asosiy egani o'chira olmaydi va `MANAGE_BOT_ADMINS` ni o'ziga bera olmaydi.
