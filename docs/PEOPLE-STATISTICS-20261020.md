# People, result inspection and readable blue controls

General Reading now returns all 105 published passages on one page. Legacy paging links canonicalize to the single filtered catalogue. Publication, canonical type filtering and learner-owned progress remain unchanged.

People hides rejected accounts unless the Rejected status is selected. Every account name links to the administrator-guarded results page, including staff accounts. The list prioritizes owner, teachers and administrators, followed by online and most recently seen students. Name, current Telegram username and owner-visible verified phone numbers are searchable with parameterized predicates. The existing bot/contact identity remains authoritative; a bounded background `getChat` refresh checks renamed or removed usernames, verifies the returned numeric identity, retains old values on errors and never changes phone verification or login bindings. Phone data remains masked from non-owner directory payloads.

Presence uses one deterministic, atomically updated snapshot per user in the existing activity store. Visible/recently used tabs send a heartbeat every 30 seconds; playing media keeps a visible tab active. The server rejects client duration/identity claims, deduplicates simultaneous tabs, suppresses rapid writes and ignores offline gaps longer than 90 seconds. Online status has a disclosed 90-second window. Duration starts at activation, not registration; unknown historical time is shown as unavailable. Presence does not update meaningful learning activity or count towards dashboard streaks. No schema migration, persistent per-heartbeat log or paid service is introduced.

The Statistics route is administrator/owner-only and appears in Management navigation. Fixed source adapters cover Academic and General Reading, Listening tests/activities/MCQ, Writing essays/typing/translation/activation/pattern practice/lessons, Speaking, Retention, Vocabulary words/games/revision, Grammar, TED/Podcast, generic lessons, assignments and mocks. Aggregate queries use persisted data and materialized source sets; incomplete and ungraded results cannot manufacture grades. Bands and percentage accuracy remain separate. Per-person results show completed full-mock summaries and a line chart, Retention averages by level and overall, all module summaries and a paginated complete result history. Teacher views retain their existing roster gate. The centre learner ranking explicitly shows the most active 100; the People directory and individual histories retain pagination for full access.

Blue surface tokens now include dark-text and accent variants. Native confirmation dialogs, custom Typing controls, flashcard faces and the separate flip button use readable foregrounds. Day wallpaper text remains dark, blue panels use light text, and the white Reading workspace remains scoped separately.

Validation: 26 unique targeted cases passed across real database, directory/query contracts, Telegram refresh, route navigation, canonical Reading facets, mock summaries and apostrophe conventions. Full production build/type validation and repository ESLint passed. Loopback HTTP rejected anonymous presence with 401 and cross-origin presence with 403. Actual browser QA used fictional accounts on the isolated restore, verified all 105 General cards, owner/staff profile access, 11 module summaries, a real fixture mock graph, 78% Retention mean from 72/84, phone/username display, online count, confirmation readability, both flashcard sides, custom Typing button colour and 480px People layout without overflow. A focused contrast scan found no remaining low-contrast blue-surface text in those inspected views. This is representative browser evidence, not a claim that every state of every site page was manually visited.
