If DATABASE_URL points to Supabase PostgreSQL, the live rows are on Supabase PostgreSQL.

- RIWI STRUCTURED DATA EXAMPLE: usage metrics
- RIWI STRUCTURED DATA EXAMPLE: version/provenance/authority/state metadata
2.3 — R2 / object storage
--------------------------------------------------------------------------------------------------------
R2 stores large files/objects. PostgreSQL stores metadata and an object key pointing to them.
